# Top Papers — AI Agents & Embodied AI (2026-07-31)

## [When Agents Do Not Stop: Uncovering Infinite Agentic Loops in LLM Agents](https://arxiv.org/abs/2607.01641)
**Authors:** Xinyi Hou, Shenao Wang, Yanjie Zhao, Haoyu Wang
**TL;DR:** Identifies and formalizes a new class of LLM agent failures called Infinite Agentic Loops (IALs), where agents endlessly repeat model calls, tool invocations, or agent handoffs without effective termination. Proposes IAL-SCAN, a static analysis tool that builds an Agentic Loop Dependence Graph to detect unbounded feedback paths in real-world agent code, preventing cost exhaustion and denial-of-service.
**Tags:** `agents`, `safety`, `reliability`, `static-analysis`, `tooling`

## [HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation](https://arxiv.org/abs/2607.04329)
**Authors:** (Arxiv 2607.04329, July 2026)
**TL;DR:** Introduces HAS-Bench, a benchmark for evaluating LLM-based Human-Agent Systems as multi-party collaborative processes where humans and agents are first-class participants. Unlike task-only evaluations, it measures process-level collaboration dynamics—communication, coordination, intervention, and shared decision-making—under configurable levels of human involvement.
**Tags:** `agents`, `human-ai-collaboration`, `benchmark`, `evaluation`, `multi-agent`

## [Can AI Agents Conduct Open-Ended AI Research? Early Evidence from Two Case Studies](https://arxiv.org/abs/2607.27191)
**Authors:** Peter Kirgis, Sayash Kapoor, Arvind Narayanan, et al. (23 authors)
**TL;DR:** Tests whether frontier AI agents can conduct open-ended AI research using "shadow evaluations"—agents tackle the central research questions of two unpublished NeurIPS 2026 papers, with the original authors grading the output. Despite completing all engineering autonomously and given six days and thousands of dollars of compute, the agents failed to make substantial progress on the actual research questions, identifying five recurring failure modes.
**Tags:** `agents`, `ai-research`, `evaluation`, `benchmark`, `limitations`

## [Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading](https://arxiv.org/abs/2607.08964)
**Authors:** Zongxia Li, Zhongzhi Li, Yucheng Shi, Ruhan Wang, Junyao Yang, Zhichao Liu, Xiyang Wu, Anhao Li, Yue Yu, Ninghao Liu, Lichao Sun, Haotao Mi, LeoweiLiang
**TL;DR:** Presents a new terminal benchmark of 46 long-horizon tasks across nine categories (experiment reproduction, software engineering, multimodal analysis, interactive games, scientific computing), addressing the gap in existing benchmarks that only test short tasks with binary outcomes. Tasks are decomposed into fine-grained subtasks enabling dense intermediate rewards and partial credit, capturing how far agents progress on open-ended workflows.
**Tags:** `agents`, `benchmark`, `evaluation`, `long-horizon`, `software-engineering`

## [AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents](https://arxiv.org/abs/2607.02255)
**Authors:** Xiangchen Cheng, Yunwei Jiang, Jianwen Sun, Zizhen Li, Chuanhao Li, Xiangcheng Cao, Yihao Liu, Fanrui Zhang, Li Jin, Kaipeng Zhang
**TL;DR:** Proposes a bounded-memory contract for long-horizon LLM agents where each decision is made from a fresh prompt assembled by typed retrieval (no raw cross-decision transcript), keeping context size constant regardless of run length and enabling ablation of individual memory components. Instantiated in Slay the Spire 2, a stochastic deck-building game requiring hundreds of tactical decisions, demonstrating that intelligent memory organization outperforms unbounded context growth.
**Tags:** `agents`, `memory`, `long-horizon`, `benchmark`, `architecture`

## [Safety Testing LLM Agents at Scale: From Risk Discovery to Evidence-Grounded Verification](https://arxiv.org/abs/2607.01793)
**Authors:** (Arxiv 2607.01793, July 2026)
**TL;DR:** Addresses the challenge of systematically testing LLM agents for safety risks at scale, proposing a pipeline from automated risk discovery through evidence-grounded verification. The work provides practical tooling for identifying failure modes before deployment and grounds safety claims in concrete behavioral evidence rather than abstract principles.
**Tags:** `agents`, `safety`, `testing`, `verification`, `red-teaming`

## [ABot-AgentOS: A General Robotic Agent OS with Lifelong Multi-modal Memory](https://arxiv.org/abs/2607.10350)
**Authors:** Jiayi Tian, Shiao Liu, Yuting Xu, Jia Lu, Zihao Guan, Honglin Han, Di Yang, Minqi Gu, Yifei Qian, Tianlin Zhang, et al. (Alibaba AMAP CV Lab)
**TL;DR:** Presents ABot-AgentOS, a robotic Agent Operating System providing a deliberative layer above low-level controllers for scene-conditioned planning, context-isolated skill execution, multi-stage verification, multi-modal memory, and edge-cloud collaboration. Introduces EmbodiedWorldBench, an executable benchmark with 16 indoor/outdoor/hybrid scenes, four difficulty levels, and 200+ tasks for navigation, object search, NPC dialogue, dynamic events, and trace-grounded scoring.
**Tags:** `embodied-ai`, `robotics`, `multi-modal`, `memory`, `benchmark`

## [ACE-Brain-0.5: A Unified Embodied Foundational Model for Physical Agentic AI](https://arxiv.org/abs/2607.04426)
**Authors:** ACE-Brain Team: Ziyang Gong, Haoming Gu, Zehang Luo, Tianyi Zhang, et al.
**TL;DR:** Introduces ACE-Brain-0.5, a unified embodied foundation model organizing robot intelligence into five coupled functions: spatial perception, decision making, embodied interaction, self-monitoring, and self-improvement. Unlike end-to-end policies (which lack spatial reasoning) or robot-agent orchestrators (which lack shared representation), it integrates all functions into a single learnable architecture for physical agents that understand, plan, act, monitor progress, and improve from experience.
**Tags:** `embodied-ai`, `robotics`, `foundation-model`, `spatial-intelligence`, `self-improvement`

## [Embodied.cpp: A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots](https://arxiv.org/abs/2607.02501)
**Authors:** (Arxiv 2607.02501, July 2, 2026)
**TL;DR:** Addresses the deployment fragmentation problem for embodied AI models—particularly Vision-Language-Action (VLA) models and world-action models—across heterogeneous robot hardware platforms. Proposes a portable C++ inference runtime that standardizes deployment, enabling the same embodied AI model to run efficiently across different robot types and compute configurations without per-platform re-engineering.
**Tags:** `embodied-ai`, `robotics`, `deployment`, `inference`, `vla`

## [Kimi K3: Open Frontier Intelligence](https://arxiv.org/abs/2607.24653)
**Authors:** Kimi Team (~400 authors, Moonshot AI)
**TL;DR:** Releases Kimi K3, a 2.8-trillion-parameter Mixture-of-Experts model with 104B activated parameters, native vision, and 1M-token context, achieving ~2.5x improvement in scaling efficiency over Kimi K2 via innovations including Kimi Delta Attention, Attention Residuals, and Stable LatentMoE (16 of 896 routed experts per token). Post-training emphasizes reinforcement learning across general, agentic, and coding domains with multiple reasoning-effort levels enabling compositional generalization and robust long-horizon execution.
**Tags:** `llm`, `moe`, `agents`, `reasoning`, `open-weights`, `frontier`

## [Evaluation and Benchmarking of LLM Agents: A Survey](https://arxiv.org/abs/2507.21504)
**Authors:** Mahmoud Mohammadi, Yipeng Li, Jane Lo, Wendy Yip
**TL;DR:** Provides a comprehensive two-dimensional taxonomy of LLM agent evaluation organized along (1) evaluation objectives—agent behavior, capabilities, reliability, and safety—and (2) evaluation process—interaction modes, datasets, metric computation, and tooling. Highlights enterprise-specific challenges often overlooked in research, including role-based data access, reliability guarantees, dynamic long-horizon interactions, and compliance requirements.
**Tags:** `agents`, `evaluation`, `benchmark`, `survey`, `reliability`, `safety`
