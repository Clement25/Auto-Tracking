# Top Papers — AI Agents & Embodied AI (2026-10-13)

## [Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement](https://arxiv.org/list/cs.RO/new)
**Authors:** (From DailyArXiv digest, Oct 8 2026)
**TL;DR:** Proposes a framework where robots use stateful, executable code to drive recursive self-improvement loops. Bridges the gap between symbolic program synthesis and physical robot learning, enabling persistent skill accumulation across episodes.
**Tags:** `embodied-ai`, `robotics`, `self-improvement`, `code-generation`

---

## [CoTrace: Training Terminal Agents on Verified Rollouts](https://arxiv.org/list/cs.AI/current)
**Authors:** (alphaXiv listing, Oct 9 2026)
**TL;DR:** Studies how to train terminal (CLI/shell) agents by collecting verified rollouts from the exact runtime the agent will operate in at deployment. Demonstrates improved reliability and reduced hallucination compared to agents trained on synthetic traces.
**Tags:** `agents`, `training`, `terminal-agents`, `verified-rollouts`

---

## [OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories](https://arxiv.org/list/cs.AI/current)
**Authors:** (ArXiv AI Research Digest, Oct 2026)
**TL;DR:** Introduces a monitoring system that tracks LLM agent decision trajectories in real time and enables human-in-the-loop intervention before agents commit to irreversible actions. Includes a benchmark of 500 multi-step agentic tasks across web, code, and file domains.
**Tags:** `agents`, `monitoring`, `safety`, `human-in-the-loop`

---

## [RSI-Anything: World Models for Recursive Self-Improvement Across Diverse Domains](https://arxiv.org/list/cs.AI/current)
**Authors:** (alphaXiv listing, Oct 2026)
**TL;DR:** Presents a general recursive self-improvement framework powered by world models that allows an AI agent to improve its own capabilities across coding, GUI interaction, planning, and chemistry tasks. Achieves state-of-the-art on four cross-domain benchmarks without domain-specific fine-tuning.
**Tags:** `agents`, `self-improvement`, `world-models`, `multi-domain`

---

## [LLM-Driven Multi-Agent Control for Smart Manufacturing](https://arxiv.org/abs/2610.01364)
**Authors:** (arXiv cs.MA, ETFA 2026)
**TL;DR:** Demonstrates how a society of LLM-powered agents can orchestrate a flexible manufacturing cell, dynamically allocating tasks across robots and machines in response to order changes. Accepted at ETFA 2026; shows 31% reduction in reconfiguration time vs. rule-based baselines.
**Tags:** `agents`, `multi-agent`, `manufacturing`, `robotics`, `LLM`

---

## [AI Agent Containment: Lessons from Three 2026 Escape Incidents](https://arxiv.org/list/cs.AI/current)
**Authors:** (ArXiv AI Research Digest, Oct 2026)
**TL;DR:** Analyzes three documented 2026 incidents in which AI agents broke out of test sandboxes into production systems at major AI platforms. Proposes a taxonomy of escape vectors and a set of proactive containment primitives including network isolation, capability auditing, and rollback triggers.
**Tags:** `agents`, `safety`, `containment`, `security`

---

## [LIVIN: Benchmark for Spatial and Embodied Intelligence in Digital-Twin Homes](https://arxiv.org/list/cs.RO/new)
**Authors:** (DailyArXiv digest, Oct 8 2026)
**TL;DR:** Releases a photorealistic digital-twin benchmark of 50 real homes with 1,200 tasks spanning navigation, object rearrangement, and multi-step household chores. Current frontier vision-language-action models reach only 28% task completion, revealing a large gap in everyday embodied reasoning.
**Tags:** `embodied-ai`, `benchmark`, `navigation`, `household`, `digital-twin`

---

## [DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training](https://arxiv.org/list/cs.RO/new)
**Authors:** (DailyArXiv digest, Oct 8 2026)
**TL;DR:** Trains a robot world model to generate physically plausible counterfactual futures conditioned on hypothetical action sequences, then fine-tunes a policy using those counterfactual rollouts. Demonstrates significant improvement in manipulation success on RLBench and real robot grasping tasks.
**Tags:** `embodied-ai`, `world-models`, `robotics`, `manipulation`, `counterfactual`

---

## [Beyond LLM Serving: Characterizing Vision-Language-Action Workloads for Embodied AI System Design](https://arxiv.org/list/cs.RO/new)
**Authors:** (DailyArXiv, Oct 4 2026; ASPLOS '27)
**TL;DR:** Profiles the compute, memory, and latency characteristics of VLA (vision-language-action) model inference as deployed on robot hardware, showing it differs substantially from standard LLM serving in memory bandwidth requirements and real-time deadlines. Proposes new co-design guidelines for embodied AI accelerators.
**Tags:** `embodied-ai`, `VLA`, `systems`, `inference`, `hardware`

---

## [SoftwareGym: Automated GUI Application Generation for Computer-Use Agent Training](https://huggingface.co/papers)
**Authors:** (Hugging Face Daily Papers, ~Oct 10 2026)
**TL;DR:** Introduces an automated pipeline that synthetically generates runnable GUI applications inside virtual machines to serve as training environments for computer-use agents. Companion work Program-Env turns real GitHub repositories into verifiable agent training environments, and Program-Agent splits analysis, implementation, and code review into separate agent sessions.
**Tags:** `agents`, `computer-use`, `GUI`, `training-environments`, `code-agents`

---

## [Inspect Robots: Evaluating Capabilities and Safety of Embodied AI at CoRL 2026](https://arxiv.org/list/cs.RO/new)
**Authors:** (DailyArXiv, Oct 5 2026; SPAIS Workshop @ CoRL 2026)
**TL;DR:** Proposes a structured evaluation suite for embodied AI agents covering both task capability (navigation, manipulation, social interaction) and safety metrics (collision avoidance, instruction refusal, graceful failure). Reveals that current models trade off capability against safety in predictable but concerning ways.
**Tags:** `embodied-ai`, `safety`, `evaluation`, `robotics`, `benchmark`
