# Top Papers — AI Agents & Embodied AI (2026-10-02)

## [TRACE: Trajectory Risk-Aware Compression for Long-Horizon Agent Safety](https://arxiv.org/abs/2606.00611)
**Authors:** (ArXiv cs.AI, Jun–Oct 2026)
**TL;DR:** Reframes long-horizon agent safety detection as trajectory-level evidence compression with a Compressor-Reader architecture. The Compressor encodes the full interaction trajectory into a compact latent evidence state under trajectory-level supervision, while the Reader uses this state as a safety reference for judgment—enabling robust safety monitoring even across very long agent runs.
**Tags:** `agents`, `safety`, `llm-agents`, `trajectory-analysis`

## [DecomposeR: DAG-Based Planner for Deep Research Agents](https://arxiv.org/abs/2606.15367)
**Authors:** (ArXiv cs.AI, 2026)
**TL;DR:** Represents research plans as typed Directed Acyclic Graphs (DAGs) where search nodes issue web queries, aggregate nodes synthesize branch conclusions, and a terminal node integrates findings. Parallel DAG execution delivers up to 3.6× speed improvements over sequential agents on knowledge-intensive research benchmarks.
**Tags:** `agents`, `research-agents`, `dag-planning`, `parallel-execution`
