# Top Papers — AI Agents & Embodied AI (2026-11-26)

## [Do LLM Agents Still Need to Be Told How to Self-Improve?](https://arxiv.org/abs/2611.23219)
**Authors:** Shobhita Sundaram, Cansu Sancaktar, Phillip Isola
**TL;DR:** Investigates whether increasingly capable LLMs can design their own self-improvement algorithms without human-specified protocols. Using a gameplay setting with a frozen LLM, the agents receive basic tools and a compute budget, then autonomously build self-learning methods via context-based optimization—achieving strategies that mirror classic self-regulated learning frameworks.
**Tags:** `agents`, `self-improvement`, `meta-learning`, `LLM`

## [Falsification-Gated Self-Evolution for LLM Agents](https://arxiv.org/abs/2611.14326)
**Authors:** Runxuan Tang et al.
**TL;DR:** Addresses "memory bloat" in long-running LLM agents by introducing a falsification-gating mechanism that decides when agents should retain or discard learned memories. The approach significantly reduces memory overhead while preserving task performance across extended deployments.
**Tags:** `agents`, `memory`, `self-evolution`, `continual-learning`, `LLM`
