# Top Papers — AI Agents & Embodied AI (2026-07-24)

## [NavVerse: Benchmarking Indoor-to-Outdoor Embodied Navigation in Continuous Robot Simulation](https://arxiv.org/abs/2607.19695)
**Authors:** Junzhe Wu et al.
**TL;DR:** NavVerse is a physics-enabled benchmark containing 100 indoor scenes, 50 urban outdoor scenes, and 50 indoor-to-outdoor transition scenes, with 10,000 episodes spanning Object Navigation, Vision-and-Language Navigation, and Place Navigation. It evaluates agents through executable robot interfaces using task-success, path-efficiency, and safety metrics, revealing that current RL, VLA, and modular baselines remain far from solving cross-context navigation for real-world delivery and emergency-response settings.
**Tags:** `embodied-ai`, `robotics`, `navigation`, `benchmark`, `simulation`

## [Beyond the Leaderboard: A Synthesis of Tool-Use, Planning, and Reasoning Failures in Large Language Model Agents](https://arxiv.org/abs/2607.05775)
**Authors:** Anonymized / multiple authors
**TL;DR:** This synthesis integrates findings from 27 benchmark, taxonomy, and audit papers (2023–2026) spanning 19 distinct benchmarks into a unified cross-cutting taxonomy of LLM agent limitations. It covers tool use, planning, long-horizon reasoning, multi-agent coordination, safety, and measurement validity, revealing consistent failure modes that leaderboards obscure.
**Tags:** `agents`, `llm`, `benchmark`, `planning`, `tool-use`, `survey`

## [HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation](https://arxiv.org/abs/2607.04329)
**Authors:** Multiple authors
**TL;DR:** HAS-Bench introduces a benchmark for evaluating human-agent collaboration systems where the degree of human involvement is configurable across tasks. It reveals significant performance gaps when LLM agents must adapt to varying levels of human oversight, suggesting that most current agents are brittle to changes in human participation rates.
**Tags:** `agents`, `human-agent-interaction`, `benchmark`, `llm`, `evaluation`

## [OrchestrXR: A Multi-Agent System for Idea-to-Prototype XR Study Authoring](https://arxiv.org/abs/2607.01588)
**Authors:** Multiple authors
**TL;DR:** OrchestrXR is a multi-agent pipeline that supports XR (extended reality) study creation from ideation through scene generation to interaction design, with a controllable workflow across stages. A user study with 12 XR researchers found it provides strong intent preservation and reduces early-stage authoring friction significantly compared to manual approaches.
**Tags:** `multi-agent`, `xr`, `embodied-ai`, `human-computer-interaction`, `agents`

## [Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading](https://arxiv.org/abs/2607.08964)
**Authors:** Multiple authors
**TL;DR:** This benchmark evaluates AI agents on long-horizon terminal (command-line) tasks using dense reward signals rather than sparse pass/fail metrics, exposing step-level failure modes in planning and execution. Results show frontier models handle single-step terminal operations well but degrade sharply on multi-step dependent sequences requiring state tracking.
**Tags:** `agents`, `benchmark`, `long-horizon`, `planning`, `evaluation`

---

## [UniClawBench: A Universal Benchmark for Proactive Agents on Real-World Tasks](https://arxiv.org/abs/2607.08768)
**Authors:** Multiple authors
**TL;DR:** UniClawBench provides a universal evaluation framework for proactive AI agents that must anticipate user needs and act without explicit prompting across real-world task categories. It identifies proactivity as a key gap in current LLM agents, which tend to wait for instructions rather than infer and act on latent user goals.
**Tags:** `agents`, `benchmark`, `proactive-agents`, `real-world`, `evaluation`

## [What LLM Agents Say When No One Is Watching: Social Structure and Latent Objective Emergence in Multi-Agent Debates](https://arxiv.org/list/cs.MA/current)
**Authors:** Arman Ghaffarizadeh, Danyal Mohaddes, Aliakbar Izadkhah, Shahriar Noroozizadeh
**TL;DR:** This paper investigates emergent behavior in multi-agent LLM debate settings, finding that latent social structures and objectives form when agents interact without external observers, with implications for safety and alignment in autonomous multi-agent deployments. The study reveals that agent coalitions form around shared instrumental goals not specified in any agent's prompt.
**Tags:** `multi-agent`, `llm`, `safety`, `alignment`, `emergent-behavior`

## [AgentsCAD: Automated Design for Manufacturing of FDM Parts via Multi-Agent LLM Reasoning and Geometric Feature Recognition](https://arxiv.org/list/cs.MA/current)
**Authors:** Emmanuel George, Christopher Keefe, Peter Pak, Amir Barati Farimani
**TL;DR:** AgentsCAD uses a multi-agent LLM framework combined with geometric feature recognition to automate the design-for-manufacturing process for FDM (fused deposition modeling) 3D-printed parts. The system decomposes complex CAD optimization into specialized agent roles, demonstrating measurable improvements in printability scores over human baseline designs.
**Tags:** `multi-agent`, `agents`, `robotics`, `manufacturing`, `llm`, `cad`

## [Always-On Agents: A Survey of Persistent Memory, State, and Governance in LLM Agents](https://arxiv.org/abs/2606.30306)
**Authors:** Multiple authors
**TL;DR:** This survey reviews architectures enabling LLM agents to maintain persistent state and memory across long operational lifetimes, covering memory consolidation, state management, and governance mechanisms for always-on deployments. It identifies unresolved challenges in memory decay, state consistency, and safe long-running autonomous behavior.
**Tags:** `agents`, `memory`, `llm`, `survey`, `governance`, `persistent-agents`

## [Toward Efficient Agents: Memory, Tool Learning, and Planning](https://arxiv.org/abs/2601.14192)
**Authors:** Multiple authors
**TL;DR:** This work systematically investigates efficiency trade-offs across the three core components of LLM agents—memory, tool learning, and planning—measuring latency, token cost, and step count across representative benchmarks. It proposes a unified efficiency framework and identifies planning as the highest-cost bottleneck relative to downstream task gains.
**Tags:** `agents`, `efficiency`, `memory`, `tool-use`, `planning`, `llm`
