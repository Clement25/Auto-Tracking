# Top Papers — AI Agents & Embodied AI (2026-09-03)

## [ComBodied Agents: a New Paradigm of Human-Centric Agentic AI](https://arxiv.org/abs/2608.10915)
**Authors:** Qianggang Ding, Xingyao Wang, Rui Feng, Zhibin Wang, Feixiang Wang, Kelong Mao, Hao Sun, Zhiyao Luo, Jiankai Tang, Lei Li, et al.
**TL;DR:** Introduces a human-centered agentic paradigm that perceives, models, predicts, and supports individual human-state trajectories over time, using software tools, sensors, wearables, robots, and human services as action channels rather than end goals. The framework unifies personal assistants, health agents, and AI companions into a closed loop with event-based multimodal perception, longitudinal correctable memory, Personal World Models, and an admissible intervention policy that respects consent, safety, and reversibility.
**Tags:** `agents`, `embodied-ai`, `human-centric`, `personal-AI`, `world-models`

## [LightNav-0: Eliciting VLM Spatial Intelligence for Generalist Embodied Navigation](https://arxiv.org/abs/2608.30935)
**Authors:** (Microsoft Research team)
**TL;DR:** A compact generalist navigation model that leverages a pretrained vision-language model's spatial reasoning via unified pointing tokens and action tokenization to achieve state-of-the-art embodied navigation across diverse tasks and robots — without task-specific prediction heads. Published August 31, 2026, LightNav-0 demonstrates that VLM spatial intelligence can be elicited and aligned with real-world robot navigation without heavy fine-tuning.
**Tags:** `embodied-ai`, `navigation`, `VLM`, `robotics`, `generalist`

## [ProgRouter: Online Progress-Guided Orchestration for Multi-Agent LLM Workflows under Quality-Cost Tradeoffs](https://arxiv.org/abs/2608.25992)
**Authors:** (arxiv August 2026)
**TL;DR:** ProgRouter is an online routing framework that adaptively selects which LLM agent handles each step of a multi-agent workflow, guided by progress signals to preserve task-solving quality while adhering to time and cost budgets. It addresses the key challenge of dynamically balancing output quality against computational cost in agentic pipelines.
**Tags:** `agents`, `multi-agent`, `LLM`, `orchestration`, `cost-optimization`

---

## [Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory](https://arxiv.org/abs/2608.07169)
**Authors:** (arxiv August 2026)
**TL;DR:** A training-free framework that transfers structured knowledge from a large teacher agent to a smaller student agent through three complementary hierarchical memory types: Workflow memory, Subtask memory, and Function memory. This enables small LLMs to perform complex agentic tasks that previously required frontier-scale models.
**Tags:** `agents`, `memory`, `LLM`, `distillation`, `efficiency`

---

## [EvoMemBench: Benchmarking Agent Memory from a Self-Evolving Perspective](https://arxiv.org/abs/2605.18421)
**Authors:** (arxiv May 2026)
**TL;DR:** EvoMemBench is a unified benchmark organized along two axes — memory scope and memory content — that compares 15 representative memory methods against strong long-context baselines under a standardized protocol. Results reveal that no single memory form works consistently across all settings, highlighting critical gaps in current agent memory research.
**Tags:** `agents`, `memory`, `benchmark`, `evaluation`, `LLM`

---

## [Zetta: Closed-Loop Embodied Robot Harness with Online Critic and Recovery](https://huggingface.co/papers)
**Authors:** Microsoft Research
**TL;DR:** Zetta evolves runtime critics and recovery skills online to govern physical robot execution at action frequency, achieving high success rates on robot benchmarks with faster inference than prior systems. The closed-loop design enables self-supervised skill improvement through real-world exploration without requiring offline data collection. Published August 17, 2026.
**Tags:** `embodied-ai`, `robotics`, `closed-loop`, `microsoft-research`, `self-supervised`

## [Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems](https://arxiv.org/list/cs.MA/recent)
**Authors:** (EMNLP 2026 Main Conference)
**TL;DR:** Introduces a gated-memory routing mechanism for multi-agent LLMs that selectively filters which observations to retain, update, or discard during online collaboration — dramatically reducing communication overhead while preserving task performance. Accepted to EMNLP 2026 Main Conference, demonstrating significant efficiency gains in collaborative agent settings.
**Tags:** `agents`, `multi-agent`, `memory`, `efficiency`, `EMNLP`

## [CAR-bench: Evaluating LLM Agent Consistency, Uncertainty, and Capability Awareness](https://arxiv.org/list/cs.AI/current)
**Authors:** (arxiv 2026)
**TL;DR:** CAR-bench is a benchmark for evaluating LLM agent consistency, uncertainty handling, and capability awareness in multi-turn tool-using scenarios. It exposes failure modes where agents confidently attempt tasks beyond their capability, providing a framework to better calibrate agent self-awareness and refusal behavior.
**Tags:** `agents`, `benchmark`, `tool-use`, `uncertainty`, `evaluation`

## [AgentSM: Semantic Memory for Agents via Execution Trace Structuring](https://arxiv.org/list/cs.AI/current)
**Authors:** (arxiv 2026)
**TL;DR:** AgentSM builds a planner agent, schema linking agent, trajectory store, and composite tools that convert past execution traces into reusable, structured semantic memory. By making historical reasoning traces searchable and composable, agents dramatically improve performance on repeated or related tasks.
**Tags:** `agents`, `memory`, `semantic`, `planning`, `tool-use`

## [Embodied.cpp: A Portable Inference Runtime for Embodied AI Models on Heterogeneous Robots](https://arxiv.org/abs/2607.02501)
**Authors:** (arxiv July 2026)
**TL;DR:** A portable C++ inference runtime that standardizes deployment of vision-language-action (VLA) models and world-action models (WAMs) across diverse heterogeneous robot hardware and edge devices — eliminating model-specific Python stacks and robot-side glue code. Submitted July 2026, it represents a key infrastructure step for scalable embodied AI deployment.
**Tags:** `embodied-ai`, `robotics`, `inference`, `edge-computing`, `VLA`, `deployment`

## [MemCtrl: Using MLLMs as Active Memory Controllers on Embodied Agents](https://arxiv.org/list/cs.RO/recent)
**Authors:** (arxiv 2026)
**TL;DR:** Augments multimodal LLMs with a trainable memory gate that decides which visual observations to retain, update, or discard during online embodied agent exploration. The active memory controller enables embodied agents to maintain compact yet informative memory representations in long-horizon tasks without memory overload.
**Tags:** `embodied-ai`, `memory`, `multimodal`, `MLLM`, `robotics`
