# Top Papers — AI Agents & Embodied AI (2026-10-05)

## [Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents](http://arxiv.org/abs/2610.02204v1)
**Authors:** Yen-Jen Wang, Haozhe Jiang, Shuying Deng, et al.
**TL;DR:** RPG enables autonomous robot improvement through simulation-based reconstruction and practice, transferring skills to the real world without manual reward engineering. Robots iteratively enhance execution capabilities through self-guided learning loops. Represents a major step toward self-evolving physical agents.
**Tags:** `embodied-ai`, `robotics`, `sim-to-real`, `self-improvement`, `reinforcement-learning`

## [Watch, Infer, Coordinate: Inferring Robot Partner Constraints for Zero-Shot Coordination](http://arxiv.org/abs/2610.02170v1)
**Authors:** Suyu Ye, Zheyuan Zhang, Vaishnav Tadiparthi, et al.
**TL;DR:** Proposes a framework enabling robots to achieve zero-shot coordination by inferring physical constraints of partner robots purely from observation, with no prior communication. This capability proves essential for collaborative tasks involving shared payloads or joint manipulation. Advances multi-robot cooperation without costly pre-programming.
**Tags:** `agents`, `multi-robot`, `zero-shot`, `coordination`, `embodied-ai`

---

## [DuoMind: Enabling Distributed Multi-Robot Coordination with Semantic Communication](http://arxiv.org/abs/2610.02161v1)
**Authors:** Hanchu Zhou, Dechen Gao, Hang Wang, et al.
**TL;DR:** DuoMind uses vision-language-action models to enable long-horizon distributed robot coordination via semantic commands rather than low-level instructions. The semantic communication protocol significantly improves adaptability and system scalability. Described as a leap forward in scalable multi-agent autonomy for real-world deployments.
**Tags:** `agents`, `multi-robot`, `semantic-communication`, `vla`, `embodied-ai`

## [AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents](http://arxiv.org/abs/2610.02163v1)
**Authors:** Xuan Zhang, Longtao Zheng, Cunxiao Du, et al.
**TL;DR:** Introduces a learnable mechanism that dynamically compresses stale context in long-horizon coding agents, preventing context overflow without sacrificing task performance. Agents learn adaptive compression strategies during extended coding sessions. Critical for scaling agentic code-generation workflows beyond current context limits.
**Tags:** `agents`, `coding-agents`, `context-compression`, `long-horizon`, `llm`

## [HumanoidToolBench: Benchmarking Humanoid Tool Use from Selection to Mobile Execution](http://arxiv.org/abs/2610.02089v1)
**Authors:** Kyochul Jang, Seohyeon Park, Ohchul Kwon, et al.
**TL;DR:** Introduces the first comprehensive benchmark evaluating humanoid robots across the full tool-use pipeline: from tool selection through locomotion-based execution. Reveals key capability gaps in current physical AI systems and provides standardized evaluation criteria. An essential resource for advancing dexterous and mobile robot intelligence.
**Tags:** `embodied-ai`, `robotics`, `benchmark`, `humanoid`, `tool-use`

---

## [KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards](http://arxiv.org/abs/2610.02206v1)
**Authors:** Pengfei Li, Naufal Suryanto, Sicheng Zhang, et al.
**TL;DR:** Presents the first runtime-free verification benchmark evaluating LLM capability in translating cybersecurity intent into executable Kali Linux commands. Addresses critical evaluation gaps in agentic security workflows by enabling safe, reproducible assessment. Fills an important niche as AI security agents become more prevalent.
**Tags:** `agents`, `cybersecurity`, `benchmark`, `tool-use`, `llm`

## [rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference](https://arxiv.org/abs/2609.19104v2)
**Authors:** (et al.)
**TL;DR:** Proposes a biologically-inspired "muscle memory" mechanism that caches and reuses motor patterns in vision-language-action models, dramatically reducing inference latency on robotic platforms. Enables VLA models to run at real-time speeds on edge devices. An important step toward practical deployment of foundation-model-based robot control.
**Tags:** `robotics`, `vla`, `efficiency`, `embodied-ai`, `inference`

## [World Action Planner: Generalizable Robot Decision-Making with Action-Conditioned World Models](https://arxiv.org/abs/2607.27599v2)

The planner grounds high-level goals in physically plausible action sequences. Demonstrates strong transfer to out-of-distribution manipulation scenarios.
