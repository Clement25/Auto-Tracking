# Top Papers — AI Agents & Embodied AI (2026-10-16)

## [Learning Self-Orchestration in Decentralized Agent Swarms](https://arxiv.org/list/cs.MA/current)
**Authors:** (from cs.MA October 16, 2026 listing)
**TL;DR:** Proposes a framework for multi-agent coordination where individual agents learn to self-organize without a central controller, using local communication and emergent role assignment. The approach shows improved robustness to agent failure versus centralized baselines.
**Tags:** `agents`, `multi-agent`, `swarms`, `decentralized`

## [Terminal-RSI: Recursive Self-Improving Terminal Agents](https://www.alphaxiv.org/)
**Authors:** (from alphaXiv trending Oct 14–15, 2026)
**TL;DR:** Introduces Terminal-RSI, a framework for agents that iteratively rewrite their own planning and tool-use code within a sandboxed terminal environment. Demonstrates self-improvement on a suite of software engineering benchmarks over multiple recursion rounds.
**Tags:** `agents`, `self-improvement`, `code-generation`, `agentic-rl`

---

## [Agents' Last Exam (ALE) v3](https://arxiv.org/abs/2606.05405)
**Authors:** (ALE benchmark team, revised Oct 9, 2026)
**TL;DR:** ALE is a benchmark of long-horizon, economically valuable tasks with verifiable outcomes designed to measure frontier agent capabilities. Version 3 expands task coverage, adds multi-tool scenarios, and tightens evaluation rubrics to reduce scoring ambiguity.
**Tags:** `agents`, `benchmark`, `evaluation`, `long-horizon`

## [Self-Evolving Agent Harnesses: A Framework for Continual Agent Improvement](https://huggingface.co/papers/trending)
**Authors:** (from Hugging Face trending Oct 13–14, 2026)
**TL;DR:** Presents a meta-learning framework that automatically updates an agent's scaffolding—its prompting strategy, tool definitions, and memory structures—based on execution traces. Evaluated across coding, web navigation, and research tasks.
**Tags:** `agents`, `meta-learning`, `scaffolding`, `continual-learning`

## [Ten Self-Distillation Methods vs. GRPO in Agentic Reinforcement Learning](https://huggingface.co/papers/trending)
**Authors:** (from Hugging Face trending Oct 13–14, 2026)
**TL;DR:** Systematically compares ten self-distillation techniques against Group Relative Policy Optimization (GRPO) for training LLM-based agents, finding that no self-distillation method consistently outperforms GRPO across diverse task types. Provides guidance on when each method excels.
**Tags:** `agents`, `reinforcement-learning`, `GRPO`, `self-distillation`

## [White-Box Probes for Detecting Sabotage in LLM Agents](https://github.com/jinming1345/agents-radar/issues/280)
**Authors:** (from agents-radar digest Oct 10, 2026)
**TL;DR:** Trains lightweight linear probes on internal activations of LLM agents to detect unverbalized deception and sabotage behaviors before they manifest in outputs. Achieves high detection rates on synthetic benchmarks without requiring external oversight models.
**Tags:** `agents`, `safety`, `interpretability`, `alignment`

## [GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions](https://github.com/luohongk/Embodied-AI-Daily/issues/1036)
**Authors:** (from Embodied-AI-Daily Oct 12, 2026)
**TL;DR:** GeniWorld learns a generative world model conditioned on visual action tokens, enabling robots to plan manipulation sequences in diverse environments by imagining outcomes. Generalizes to unseen object categories and scene configurations in zero-shot settings.
**Tags:** `embodied-ai`, `robotics`, `world-model`, `manipulation`

---

## [UNITAS: A 3D-Native World Action Model for Embodied Manipulation](https://github.com/luohongk/Embodied-AI-Daily/issues/1036)
**Authors:** (from Embodied-AI-Daily Oct 12, 2026)
**TL;DR:** UNITAS processes native 3D point-cloud observations directly, avoiding the information loss of 2D projection, and jointly learns action prediction and scene dynamics in a single transformer. Demonstrates state-of-the-art performance on RLBench and a real-world robot arm.
**Tags:** `embodied-ai`, `robotics`, `3D-vision`, `manipulation`

## [LIVIN: Benchmarking Spatial and Embodied Intelligence in Digital Twins of Lived-In Homes](https://github.com/Ponkux/DailyArXiv-cp/issues/588)

**TL;DR:** LIVIN introduces a benchmark built from digital twins of real, occupied home environments, testing an agent's spatial reasoning, long-horizon navigation, and interaction under realistic clutter and occlusion. Existing models score far below human baselines.

## [OmniDex: Scaling Dexterous Hand Grasping to Diverse Cluttered Scenes](https://github.com/Ponkux/DailyArXiv-cp/issues/588)
**Authors:** (from DailyArXiv-cp Oct 10, 2026)
**TL;DR:** OmniDex scales dexterous multi-finger grasping to cluttered tabletop scenes by combining a large-scale synthetic data pipeline with sim-to-real transfer via domain randomization. Achieves 85% success on 200+ unseen object categories in real-robot experiments.
**Tags:** `embodied-ai`, `robotics`, `dexterous-manipulation`, `sim-to-real`

## [ChunkAct: Action Chunking for Agentic Robotics](https://arxiv.org/abs/2610.18874)
**Authors:** (arXiv 2610.18874, submitted Oct 14, 2026)
**TL;DR:** ChunkAct reformulates robot control as predicting variable-length action chunks rather than single-step actions, improving both execution smoothness and long-horizon task success. The method integrates with existing vision-language policy architectures with minimal modification.
**Tags:** `embodied-ai`, `robotics`, `action-chunking`, `policy-learning`

## [Inspect Robots: Evaluating the Capabilities and Safety of Embodied AI](https://github.com/Ponkux/DailyArXiv-cp/issues/586)

**TL;DR:** Provides a structured evaluation framework for assessing both the task performance and safety properties of embodied AI systems, including metrics for unintended contact, constraint violations, and out-of-distribution recovery. Applied to six representative robot platforms.
