# Top Papers — AI Agents & Embodied AI (2026-08-08)

## [Spatial Reasoning in LLM Game Agents: Impact of Causal Context and Multi-Step Planning](https://arxiv.org/abs/2607.22732)
**Authors:** (arXiv:2607.22732)
**TL;DR:** Examines failures in LLM-based game agents on complex tasks, evaluating whether causal prompt augmentation and multi-step planning can improve performance while managing response latency. Experiments use the Qwen3 model family across varying model scales, reasoning modes, and planning horizons. Provides concrete guidance on when multi-step planning helps vs. hurts agent performance.
**Tags:** `agents`, `llm`, `planning`, `spatial-reasoning`, `game-agents`

## [HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation](https://arxiv.org/abs/2607.04329)
**Authors:** (arXiv:2607.04329)
**TL;DR:** Introduces HAS-Bench, a benchmark that evaluates human-agent collaboration systems with configurable levels of human participation. Tests how well LLM agents adapt their behavior and autonomy depending on how much oversight or input is provided by a human collaborator. Highlights gaps in current models when human involvement is partial or asynchronous.
**Tags:** `agents`, `human-ai-collaboration`, `benchmark`, `evaluation`, `llm`

## [Harnessing the Collective Intelligence of AI Agents in the Wild for New Discoveries](https://arxiv.org/abs/2606.10402)
**Authors:** (arXiv:2606.10402)
**TL;DR:** Proposes a framework for aggregating insights from large populations of AI agents operating across diverse real-world environments to accelerate scientific discovery. Demonstrates that pooling observations from many specialized agents outperforms single-agent baselines on open-ended discovery tasks. Introduces mechanisms for filtering noise and de-duplicating findings from heterogeneous agent outputs.

## [Self-Evolving World Models for LLM Agent Planning](https://arxiv.org/abs/2606.30639)
**Authors:** (arXiv:2606.30639)
**TL;DR:** Presents a framework where LLM agents build and iteratively refine internal world models from environment interactions, enabling better long-horizon planning without external supervision. The self-evolving world model allows agents to predict consequences of actions and recover from mistakes mid-trajectory. Outperforms static planning baselines on sequential decision-making benchmarks.
**Tags:** `agents`, `world-models`, `planning`, `llm`, `reinforcement-learning`

## [Skill-MAS: Evolving Meta-Skill for Automatic Multi-Agent Systems](https://arxiv.org/abs/2606.18837)
**Authors:** (arXiv:2606.18837)
**TL;DR:** Proposes Skill-MAS, a framework that automatically evolves reusable meta-skills shared across agents in a multi-agent system, reducing redundant learning and improving coordination. Meta-skills are distilled from successful agent trajectories and injected into new agents as initialization priors. Achieves significant sample efficiency gains on cooperative multi-agent benchmarks.
**Tags:** `multi-agent`, `skill-learning`, `meta-learning`, `autonomous-agents`

## [Benchmarking Autonomous Agents against Temporal, Spatial, and Semantic Evasions](https://arxiv.org/abs/2605.22321)
**Authors:** (arXiv:2605.22321)
**TL;DR:** Constructs A3S-Bench, a comprehensive benchmark of 2,254 real-world agent execution trajectories that tests robustness of autonomous agents against temporal, spatial, and semantic perturbations. Evaluates a standard agent framework integrated with 10 mainstream LLM backbones across 20 practical threat scenarios. Reveals that most frontier models remain vulnerable to structured semantic evasions.
**Tags:** `agents`, `benchmark`, `robustness`, `evaluation`, `security`

## [A Brain-inspired Embodied Intelligence for Fluid and Fast Reflexive Robotics Control](https://arxiv.org/abs/2601.14628)
**Authors:** (arXiv:2601.14628)
**TL;DR:** Presents NeuroVLA (Neuromorphic Vision-Language-Action), a framework mimicking the structural organization of the bio-nervous system — cortex, cerebellum, and spinal cord — for robot control. A high-level VLA model plans goals while an adaptive cerebellum module stabilizes motion using high-frequency sensor feedback without full LLM inference per step. Achieves real-time reflexive control latency previously unattainable with standard VLA architectures.
**Tags:** `embodied-ai`, `robotics`, `neuromorphic`, `vision-language-action`, `real-time-control`

## [AgencyBench: Benchmarking the Frontiers of Autonomous Agents in 1M-Token Real-World Contexts](https://arxiv.org/abs/2601.11044)
**Authors:** (arXiv:2601.11044)
**TL;DR:** Introduces AgencyBench, targeting LLM-based autonomous agents in long-context real-world scenarios with contexts up to 1 million tokens, capturing challenges existing benchmarks fail to address. Tests agents on multi-document reasoning, cross-session memory, and tool-augmented long-horizon tasks. Finds that even frontier models degrade significantly beyond 200K tokens of context in agentic settings.
**Tags:** `agents`, `benchmark`, `long-context`, `evaluation`, `llm`

## [SW-A²-Bench: Benchmarking Autonomous Software Agent Generation for Agentic Web](https://arxiv.org/abs/2604.04226)
**Authors:** (arXiv:2604.04226)
**TL;DR:** The first benchmark specifically designed for autonomous software agent generation, evaluating whether generated agents are faithful to source repositories and can interoperate in multi-agent workflows on the web. Covers agent generation fidelity, API compatibility, and end-to-end integration testing in realistic agentic web environments. Reveals that code-generating LLMs frequently produce agents with subtle API mismatches that only surface in multi-agent integration.
**Tags:** `agents`, `software-engineering`, `benchmark`, `agentic-web`, `code-generation`
