# Top Papers — AI Agents & Embodied AI (2026-11-12)

## [Steering Emergent Behavior in Multi-Agent LLM Systems via Information Networks](https://arxiv.org/abs/2611.11714)
**Authors:** Sepehr Ilami, Babak Heydari
**TL;DR:** Treats the observation topology of a multi-agent LLM group as a design variable. A manager with a limited budget adds information links between ten identical agents playing repeated group-decision games, steering emergent collective behavior without changing any individual agent's policy.
**Tags:** `agents`, `multi-agent`, `llm`, `emergence`, `information-theory`

## [Signed but Not Safe: Requirement Integrity in LLM Agent Handoffs](https://arxiv.org/abs/2611.07483)
**Authors:** (not listed in source)
**TL;DR:** Examines whether requirements stay intact when tasks are handed between LLM agents in a pipeline. Demonstrates that signing alone does not prevent requirement drift and proposes integrity checks at each handoff boundary.

## [World In-Context Learning for Agentic Robot Manipulation](https://arxiv.org/abs/2611.12885)

## [Computer-Use Agents Are Embodied Generalists](https://arxiv.org/abs/2611.09847)
**Authors:** (not listed in source)
**TL;DR:** Argues that GUI-operating computer-use agents should be viewed through the lens of embodied AI rather than pure language modeling. The paper shows that lessons from robot navigation and manipulation — perception, memory, and action grounding — transfer directly to improving GUI agents.
**Tags:** `agents`, `embodied-ai`, `computer-use`, `gui-agents`, `llm`

## [Is Your Robot's Memory Just a Clock? Temporal Shortcuts in Memory-Augmented VLA Policies](https://arxiv.org/abs/2611.14488)
**Authors:** (not listed in source)
**TL;DR:** Investigates whether the memory modules in vision-language-action policies actually store semantic task state or simply learn temporal shortcuts (i.e., elapsed-time proxies). Shows that ablating memory reduces performance primarily on tasks requiring genuine state recall, not on those where timing suffices.
**Tags:** `robotics`, `embodied-ai`, `memory`, `vla`, `evaluation`

## [DexSeed: Expanding Human Hand-Object Interactions into Robot Demonstrations for Dexterous Policy Learning](https://arxiv.org/abs/2611.14092)
**Authors:** (not listed in source)
**TL;DR:** Automatically converts human hand-object interaction videos into robot dexterous manipulation demonstrations by retargeting hand poses to robot hand kinematics. The resulting demonstrations serve as seeds for imitation learning, dramatically reducing the need for costly robot teleoperation.
**Tags:** `robotics`, `dexterous-manipulation`, `imitation-learning`, `embodied-ai`, `data-collection`
