# Top Papers — AI Agents & Embodied AI (2026-09-22)

## [An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency](https://arxiv.org/abs/2609.22043)
**Authors:** (see arxiv)
**TL;DR:** Proposes a three-signal memory decision framework for LLM agents that decouples confidence from consistency to determine when agents should write, retrieve, or discard memories. The approach improves interpretability of agent memory operations and shows gains on multi-hop reasoning benchmarks requiring long-term context retention.
**Tags:** `agents`, `memory`, `llm`, `interpretability`

## [APort Vault: Benchmarking AI Agent Payment Authorization with the Open Agent Passport](https://arxiv.org/abs/2609.22076)
**Authors:** (see arxiv)
**TL;DR:** Introduces a benchmark and identity framework (Open Agent Passport) for evaluating AI agents' ability to securely handle payment authorization tasks, covering scenarios involving delegation, fraud detection, and user consent. Finds that current frontier agents frequently authorize payments outside their granted scope.
**Tags:** `agents`, `security`, `benchmarking`, `finance`, `tool-use`

---

## [Value-Sensitive Delegation in Everyday AI Agent Use: Evidence from OpenClaw](https://arxiv.org/abs/2609.22067)
**Authors:** (see arxiv)
**TL;DR:** Empirically studies how users delegate tasks to AI agents in a real-world agentic platform (OpenClaw), finding that users' delegation choices are tightly coupled to personal values around privacy, autonomy, and accountability. Proposes design guidelines for value-sensitive agent interfaces that make delegation scope explicit.
**Tags:** `agents`, `human-ai-interaction`, `values`, `delegation`, `ux`

---

## [CIPL: A Channel-Aware Framework for Recoverable Privacy Leakage in LLM Agents](https://arxiv.org/abs/2609.21686)
**Authors:** (see arxiv)
**TL;DR:** Presents CIPL, a privacy defense framework for LLM agents that models information leakage at the channel level across tool calls, memory reads, and API responses. Unlike prior work, CIPL supports recoverable leakage — enabling agents to continue operation after partial data exposure while minimizing sensitive-data propagation.
**Tags:** `agents`, `privacy`, `security`, `llm`, `tool-use`

---

## [Bayesian Belief Layer for Controllable Opinion Dynamics in LLM Agents](https://arxiv.org/abs/2609.21997)
**Authors:** (see arxiv)
**TL;DR:** Adds a Bayesian belief-update module on top of an LLM agent's reasoning layer to model how agents should revise their "opinions" as new evidence arrives during multi-turn interactions. The mechanism enables controlled, principled opinion dynamics and reduces susceptibility to sycophancy in debate simulations. Accepted to the REALM workshop.
**Tags:** `agents`, `belief-update`, `opinion-dynamics`, `multi-agent`, `sycophancy`

---

## [MOSCOPT: Mixture-of-Skills Collective Optimization for LLM Agents](https://arxiv.org/abs/2609.14399)
**Authors:** (see arxiv)
**TL;DR:** Frames multi-agent task completion as a mixture-of-skills problem where agents with heterogeneous skill profiles collectively optimize task allocation and execution. MOSCOPT uses a hierarchical scheduler to match tasks to skill-appropriate agents dynamically, outperforming homogeneous agent pools on complex coding and tool-use benchmarks.
**Tags:** `agents`, `multi-agent`, `skill-routing`, `optimization`, `llm`

---

## [Do AI Agents Understand Computer Architecture?](https://arxiv.org/abs/2609.19387)
**Authors:** Ambika Sharan, Grigory Chirkov, Soheil Abbasloo
**TL;DR:** Evaluates how well frontier LLM-based agents (including GPT-6 Astra and Claude Opus 5.5) can reason about and design computer hardware components such as cache controllers, branch predictors, and memory hierarchies. Finds significant gaps in low-level microarchitecture reasoning and proposes a new hardware-design benchmark for AI agents.
**Tags:** `agents`, `hardware-design`, `evaluation`, `benchmarking`, `llm`

## [An Unexpected Robot Policy: Early Evaluations of GPT-6 Astra on RoboDojo and Beyond](https://arxiv.org/abs/2609.24170)
**Authors:** (see arxiv)
**TL;DR:** Documents the first systematic evaluation of GPT-6 Astra as a zero-shot robot policy across the RoboDojo benchmark suite and several real-world manipulation tasks. Finds that Astra, without any robot-specific fine-tuning, achieves surprisingly competitive performance on instruction-following tasks while failing on precision dexterous manipulation.
**Tags:** `embodied-ai`, `robotics`, `vla`, `evaluation`, `foundation-models`, `gpt-6`

## [In-Context Robot Learning with VLM Agents](https://arxiv.org/abs/2609.19138)
**Authors:** (see arxiv)
**TL;DR:** Proposes a framework for in-context learning of new robot manipulation skills via vision-language model agents, enabling a robot to adapt to novel tasks from a handful of demonstration videos without gradient updates. Achieves state-of-the-art few-shot performance on the RLBench and MetaWorld benchmarks.
**Tags:** `embodied-ai`, `vlm`, `robotics`, `in-context-learning`, `few-shot`

## [Bridge3D: Enabling Vision-Language-Action Models to See and Act in 3D](https://arxiv.org/abs/2609.24525)
**Authors:** (see arxiv)
**TL;DR:** Extends standard 2D VLA models with an explicit 3D spatial understanding module that grounds language instructions and visual inputs into a unified 3D scene representation before generating robot actions. Bridge3D significantly improves manipulation success rates in cluttered environments compared to 2D-only VLAs.
**Tags:** `embodied-ai`, `vla`, `3d-perception`, `robotics`, `manipulation`

## [RoboFolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects](https://arxiv.org/abs/2609.10243)
**Authors:** (see arxiv)
**TL;DR:** Introduces RoboFolDeX, a real-robot benchmark targeting long-horizon manipulation of deformable objects (cloth, ropes, cables) across 20 tasks requiring multi-step planning and contact-rich interaction. Evaluates 12 recent robot learning methods and finds that deformable manipulation remains a significant open challenge for current approaches.
