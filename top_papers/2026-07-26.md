# Top Papers — AI Agents & Embodied AI (2026-07-26)

## [ASPIRE: Agentic Skills Discovery for Robotics](https://arxiv.org/abs/2607.00272)
**Authors:** NVIDIA GEAR Lab et al.
**TL;DR:** ASPIRE is a continual learning system that autonomously writes and refines robot control programs in a code-as-policy paradigm, compounding experience into a reusable, transferable skill library. It runs an open-ended loop with a closed-loop execution engine, evolutionary task search, and multimodal failure diagnosis. ASPIRE surpasses prior methods by up to 77% on LIBERO-Pro, 72% on bimanual handover tasks, and 32% on long-horizon BEHAVIOR-1K household tasks.
**Tags:** `embodied-ai`, `robotics`, `skill-discovery`, `code-as-policy`, `manipulation`

## [ACE: Agentic Control for Embodied Manipulation via Zero-shot Workflow Reasoning](https://arxiv.org/abs/2607.04162)
**Authors:** (arXiv 2607.04162)
**TL;DR:** ACE introduces zero-shot workflow reasoning for embodied manipulation, enabling agents to decompose and execute complex manipulation tasks without task-specific training. The framework leverages LLM reasoning over structured workflow graphs to control robot arms in multi-step scenarios. It bridges high-level task understanding with low-level motor control through an agentic planning hierarchy.
**Tags:** `embodied-ai`, `manipulation`, `zero-shot`, `workflow-reasoning`, `agents`

## [Embodied.cpp: A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots](https://arxiv.org/abs/2607.02501)
**Authors:** (arXiv 2607.02501)
**TL;DR:** Embodied.cpp presents a C++ inference runtime specifically designed for deploying embodied AI models on heterogeneous robot hardware, addressing the challenges of multi-rate execution in closed-loop control. The runtime supports diverse hardware backends and decouples perception, reasoning, and action modules for flexible deployment. It enables frontier vision-language-action models to run efficiently on resource-constrained robot platforms.
**Tags:** `embodied-ai`, `robotics`, `inference`, `edge-deployment`, `heterogeneous-hardware`

## [HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation](https://arxiv.org/abs/2607.04329)
**Authors:** (arXiv 2607.04329)
**TL;DR:** HAS-Bench is a benchmark for evaluating LLM-based human-agent collaboration systems, with configurable levels of human participation across tasks. It measures how agents adapt their autonomy and communication when humans provide varying degrees of guidance or intervention. The benchmark reveals significant gaps in current agents' ability to seamlessly handle the full spectrum from fully autonomous to heavily supervised operation.
**Tags:** `agents`, `human-agent-interaction`, `benchmark`, `evaluation`, `human-in-the-loop`

## [MECoBench: A Systematic Study of Multimodal Agent Collaboration in Embodied Environments](https://arxiv.org/abs/2606.31966)
**Authors:** Qingyun Liu, Jiwen Zhang, Jingyi Hu, Siyuan Wang, Zhongyu Wei
**TL;DR:** MECoBench introduces a multimodal embodied cooperation benchmark spanning diverse real-world tasks, two cooperation structures, and three collaboration modes, providing a systematic testbed for multi-agent embodied AI. Key findings show that collaboration generally improves task completion but benefits depend critically on balancing collaborative gains against coordination overhead. Communication is found to be essential for collaboration gains, while the best mode depends on team size and model capability.
**Tags:** `embodied-ai`, `multi-agent`, `benchmark`, `multimodal`, `collaboration`

## [MemTool: Optimizing Short-Term Memory Management for Dynamic Tool Calling in LLM Agent Multi-Turn Conversations](https://arxiv.org/abs/2507.21428)
**Authors:** (arXiv 2507.21428)
**TL;DR:** MemTool addresses the challenge of managing short-term memory in LLM agents engaged in long multi-turn conversations with dynamic tool calls, where context windows are easily overwhelmed. The system introduces selective memory compression and retrieval mechanisms that prioritize relevant tool outputs while discarding noise. Experiments show improved task completion rates and reduced token costs on tool-heavy agentic benchmarks.
**Tags:** `agents`, `memory`, `tool-use`, `LLM`, `multi-turn`

The approach demonstrates improved mission success rates for long-horizon underwater inspection and exploration tasks.

## [A Survey: Learning Embodied Intelligence from Physical Simulators and World Models](https://arxiv.org/abs/2507.00917)
**Authors:** (arXiv 2507.00917)
**TL;DR:** This comprehensive survey examines how physical simulators and world models are being used to train embodied AI agents capable of perceiving, reasoning, and acting in the physical world. The paper categorizes approaches by simulation fidelity, world model architecture, and transfer methodology (sim-to-real gap). It identifies key open challenges including contact-rich manipulation, multi-body dynamics, and efficient real-world adaptation.
**Tags:** `embodied-ai`, `world-models`, `simulation`, `survey`, `sim-to-real`

## [Cortex: A Bidirectionally Aligned Embodied Agent Framework for Long-horizon Manipulation](https://arxiv.org/abs/2607.05377)
**Authors:** (arXiv 2607.05377)
**TL;DR:** Cortex introduces bidirectional alignment between high-level task understanding and low-level motor control for long-horizon robotic manipulation, addressing the common failure modes of cascading errors in extended task sequences. The framework uses a closed-loop feedback mechanism where execution outcomes continuously refine the task plan. Evaluated on multi-step household manipulation benchmarks, Cortex substantially outperforms single-pass planning baselines.
**Tags:** `embodied-ai`, `manipulation`, `long-horizon`, `planning`, `robotics`

## [Always-On Agents: A Survey of Persistent Memory, State, and Governance in LLM Agents](https://arxiv.org/abs/2606.30306)
**Authors:** (arXiv 2606.30306)
**TL;DR:** This survey examines the emerging paradigm of persistent LLM agents that maintain state across sessions, covering memory architectures, state management strategies, and governance mechanisms for long-running autonomous systems. The paper analyzes the trade-offs between memory fidelity, privacy, and computational cost in always-on agent deployments. It also addresses open challenges in auditing and controlling agents that accumulate knowledge and behaviors over time.
**Tags:** `agents`, `memory`, `persistent-agents`, `governance`, `survey`

## [Advancing Omnimodal Embodied Agents from Isolated Skills to Everyday Physical Autonomy](https://arxiv.org/abs/2606.27251)
**Authors:** (arXiv 2606.27251)
**TL;DR:** This paper proposes a framework for composing isolated embodied skills into coherent everyday physical autonomy, addressing the gap between narrow task-specific robot capabilities and generalist home assistant behavior. The approach uses an omnimodal foundation model to ground skill selection and sequencing in language, vision, and proprioception jointly. Results show strong generalization to novel household task combinations not seen during training.
**Tags:** `embodied-ai`, `robotics`, `skill-composition`, `omnimodal`, `physical-autonomy`
