# Top Papers — AI Agents & Embodied AI (2026-07-25)

## [NavVerse: Benchmarking Indoor-to-Outdoor Embodied Navigation in Continuous Robot Simulation](https://arxiv.org/abs/2607.19695)
**Authors:** Junzhe Wu et al. (University of Michigan, Tsinghua University)
**TL;DR:** NavVerse introduces a physics-enabled benchmark with 100 indoor, 50 outdoor, and 50 transitional scenes (10,000 episodes) for continuous indoor-to-outdoor robot navigation. It covers Object Navigation, Vision-and-Language Navigation, and Place Navigation tasks, exposing failures—kinodynamic, boundary-traversal, and scene-transition—that isolated benchmarks miss.
**Tags:** `embodied-ai`, `navigation`, `robotics`, `benchmark`, `simulation`

## [RynnWorld-4D: 4D Embodied World Models for Robotic Manipulation](https://arxiv.org/abs/2607.06559)
**Authors:** Haoyu Zhao, Xingyue Zhao, Siteng Huang, Xin Li, Deli Zhao, Zhongyu Li (Alibaba DAMO Academy)
**TL;DR:** RynnWorld-4D is a generative world model that co-produces future RGB frames, depth maps, and optical flow from a single RGB-D image and a language instruction in a single unified diffusion process. The synchronized RGB-DF representation captures 4D scene dynamics, and the derived policy achieves state-of-the-art on real-world dexterous bimanual manipulation tasks requiring spatial precision and temporal coordination.
**Tags:** `embodied-ai`, `robotics`, `manipulation`, `world-models`, `diffusion`, `VLA`

## [AgentGym2: Benchmarking Large Language Model Agents in De-Idealized Real-World Environments](https://arxiv.org/abs/2607.05174)
**Authors:** Zhiheng Xi, Dingwen Yang, et al. (Fudan University)
**TL;DR:** AgentGym2 evaluates LLM agents in realistic, noisy, underspecified environments where agents must proactively discover tools rather than relying on pre-packaged interfaces. It measures end-to-end procedure execution, tool discovery via exploration, and robustness to noise—revealing that even state-of-the-art models like GPT-5 and Gemini struggle significantly on de-idealized tasks.
**Tags:** `agents`, `benchmark`, `evaluation`, `LLM-agents`, `tool-use`

## [AgentAbstain: Do LLM Agents Know When Not to Act?](https://arxiv.org/abs/2607.10059)
**Authors:** Submitted July 11, 2026
**TL;DR:** The first systematic evaluation framework for agentic abstention: the calibrated ability of tool-using LLM agents to recognize when not to act. Current benchmarks focus overwhelmingly on task success, ignoring whether agents appropriately refrain in ambiguous or risky situations—a critical safety property for autonomous deployment.
**Tags:** `agents`, `safety`, `evaluation`, `abstention`, `LLM-agents`

## [ProACT: Towards Breakdown-Aware Proactive Agent in Multi-User Collaboration](https://arxiv.org/abs/2607.03730)
**Authors:** Shu Yang, Difei Xu, Jiaxin Pei, Di Wang
**TL;DR:** ProACT is a framework for proactive agents in multi-user collaboration that observes speaker-attributed conversation history, detects intervention-worthy breakdowns, and chooses between silence and targeted group-facing interventions. Evaluated across five LLM backbones, it improves appropriateness and reduces unnecessary interruptions while preserving useful interventions.
**Tags:** `agents`, `multi-agent`, `collaboration`, `proactive`, `conversational-AI`

## [Embodied.cpp: A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots](https://arxiv.org/abs/2607.02501)
**Authors:** Submitted July 2, 2026
**TL;DR:** Embodied.cpp provides a modular, multi-rate execution runtime with latency-first fused inference and extensible operator/I/O support, enabling deployment of embodied AI models across heterogeneous devices, robots, and simulators through a single backend abstraction—lowering the barrier to real-world robot deployment.
**Tags:** `embodied-ai`, `robotics`, `inference`, `deployment`, `runtime`

## [OrchestrXR: A Multi-Agent System for Idea-to-Prototype XR Study Authoring](https://arxiv.org/abs/2607.01588)
**Authors:** Submitted July 2, 2026
**TL;DR:** OrchestrXR automates the full pipeline from research idea to deployed XR study prototype using a multi-agent LLM system. Specialized subagents handle study design, scene generation, participant flow, and code synthesis—demonstrating LLM agents' capacity for complex, multi-step creative and technical authoring workflows.
**Tags:** `agents`, `multi-agent`, `XR`, `code-generation`, `automation`

## [HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation](https://arxiv.org/abs/2607.04329)
**Authors:** Submitted July 2026
**TL;DR:** HAS-Bench is a benchmark for human-agent collaboration that systematically varies the level of human participation, exposing how well LLM agents adapt their behavior—initiative, delegation, explanation—depending on how actively a human co-operator is engaged. It fills a gap in benchmarks that evaluate only fully autonomous operation.
**Tags:** `agents`, `human-agent-interaction`, `benchmark`, `evaluation`, `collaboration`

## [Cortex: A Bidirectionally Aligned Embodied Agent Framework for Long-horizon Manipulation](https://arxiv.org/abs/2607.05377)
**Authors:** Submitted July 2026
**TL;DR:** Cortex introduces bidirectional alignment between high-level semantic planning and low-level motor control, enabling robust execution of long-horizon manipulation tasks. The framework addresses compounding errors in sequential manipulation by coupling top-down task decomposition with bottom-up skill feedback loops.
**Tags:** `embodied-ai`, `robotics`, `manipulation`, `planning`, `long-horizon`

## [From Signals to Structure: How Memory Architecture Drives Language Emergence in LLM Agents](https://arxiv.org/list/cs.MA/recent)
**Authors:** Submitted July 2026
**TL;DR:** This paper examines how different memory architectures—episodic, semantic, working memory—influence whether coherent task-relevant language emerges in LLM agents operating in multi-agent environments. Experiments reveal that structured memory layouts substantially shape communication protocols that emerge through interaction.
**Tags:** `agents`, `multi-agent`, `memory`, `language-emergence`, `LLM-agents`
