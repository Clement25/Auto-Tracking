# Top Papers — AI Agents & Embodied AI (2026-09-07)

## [The Natural Language Interaction Protocol and Standard for AI Agents](https://arxiv.org/abs/2609.04135)
**Authors:** (Ecma International TC56 Working Group)
**TL;DR:** Proposes a standardized application-layer protocol for heterogeneous AI agent interaction, formally adopted by Ecma International. Addresses the growing need for interoperability as agents built on different frameworks must communicate and collaborate across organizational and technical boundaries.
**Tags:** `agents`, `interoperability`, `standards`, `multi-agent`, `protocol`

---

## [Remember and Reweight: Enhancing Multi-Agent Debate with Experience Memory and Confidence Estimation](https://arxiv.org/abs/2609.03619)
**Authors:** (Multiple, EMNLP 2026)
**TL;DR:** Introduces a memory-augmented multi-agent debate framework where agents accumulate experience across rounds and dynamically reweight their contributions based on confidence scores. Demonstrates consistent accuracy gains over vanilla debate on reasoning benchmarks. Accepted to EMNLP 2026.
**Tags:** `multi-agent`, `debate`, `memory`, `reasoning`, `llm-agents`

---

## [When Users Don't Ask: Benchmarking Context-Driven Memory Retrieval in Conversational Agents](https://arxiv.org/abs/2609.03467)
**Authors:** (Multiple)
**TL;DR:** Introduces a benchmark and evaluation protocol for assessing whether conversational agents can proactively retrieve and surface relevant memories without explicit user prompts. Finds that current agents significantly underperform humans in context-driven memory anticipation tasks.
**Tags:** `agents`, `memory`, `benchmarking`, `conversational-ai`, `evaluation`

---

## [Codebook Agent: Amortized Topology Design for LLM Multi-Agent Systems](https://arxiv.org/abs/2609.02242)
**Authors:** (Multiple)
**TL;DR:** Presents a method to automatically design multi-agent communication topologies by learning a codebook of reusable graph patterns, amortizing the expensive topology search across tasks. Achieves state-of-the-art performance on multi-agent reasoning tasks while reducing overhead.
**Tags:** `multi-agent`, `graph-topology`, `agent-design`, `llm-agents`, `efficiency`

---

## [EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents](https://arxiv.org/abs/2609.01281)
**Authors:** (Multiple)
**TL;DR:** Proposes a unified framework for vision-language-action (VLA) agents that integrates skill orchestration, online training, and deployment under a single interface. Enables long-horizon robotic task completion by coordinating perception, planning, execution, and recovery in closed-loop.
**Tags:** `embodied-ai`, `robotics`, `vla`, `skill-learning`, `deployment`

---

## [Invalidation Contracts for Cross-Episode Agent Memory](https://arxiv.org/abs/2609.00248)
**Authors:** (Multiple)
**TL;DR:** Introduces the concept of "invalidation contracts" — declarative constraints agents attach to stored memories that specify when they should be automatically discarded or revised. Addresses the problem of stale memory harming agent performance across long-horizon, multi-episode deployments.
**Tags:** `agents`, `memory`, `long-horizon`, `episodic-memory`, `knowledge-management`

---

## [Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems](https://arxiv.org/abs/2609.00237)
**Authors:** (Multiple)
**TL;DR:** Proposes a gated-memory routing mechanism that selectively propagates information between agents in a multi-agent LLM system, reducing token overhead while preserving task-relevant context. Achieves up to 40% communication reduction with minimal accuracy loss on collaborative reasoning tasks.
**Tags:** `multi-agent`, `memory`, `efficiency`, `routing`, `llm-agents`

---

## [HyperAgent: Planning and Acting over Tool-Schema Hypergraphs for Tool-Use LLM Agents](https://arxiv.org/abs/2608.02650)
**Authors:** (Multiple)
**TL;DR:** Represents API tool schemas as hypergraphs to capture higher-order relationships among tools, enabling more structured multi-step planning. HyperAgent outperforms ReAct-style baselines on complex multi-tool benchmarks by reasoning over tool dependencies before calling them.
**Tags:** `agents`, `tool-use`, `planning`, `hypergraph`, `api-agents`

---

## [ACE-Brain-0.5: A Unified Embodied Foundational Model for Physical Agentic AI](https://arxiv.org/abs/2607.04426)
**Authors:** (Multiple)
**TL;DR:** Introduces ACE-Brain-0.5, a foundation model unifying perception, planning, and action for physical robotic agents. Trained on diverse cross-embodiment datasets, it achieves strong zero-shot generalization across manipulation and navigation tasks in both simulation and real hardware.
**Tags:** `embodied-ai`, `foundation-model`, `robotics`, `cross-embodiment`, `physical-ai`

---

## [Advancing Omnimodal Embodied Agents from Isolated Skills to Everyday Physical Autonomy](https://arxiv.org/abs/2606.27251)
**Authors:** (Multiple)
**TL;DR:** Proposes a compositional architecture that combines vision, language, and force-feedback modalities to lift isolated robot skills into coherent everyday physical autonomy. Demonstrates sustained household task completion over 30-minute uninterrupted episodes in a real home environment.
**Tags:** `embodied-ai`, `robotics`, `omnimodal`, `household-autonomy`, `skill-composition`
