# Top Papers — AI Agents & Embodied AI (2026-10-23)

## [Memory-Centric Continual Learning for AI Agents](https://arxiv.org/abs/2610.29357)
**Authors:** arXiv:2610.29357 (submitted 21 Oct 2026)
**TL;DR:** Addresses the challenge of AI agents that must learn from experience over long deployments without forgetting prior knowledge. Proposes a memory-centric architecture that enables continual learning in deployed agent systems, preventing catastrophic forgetting while incorporating new experience.
**Tags:** `agents`, `continual-learning`, `memory`, `deployment`

## [The Cost of Saying Hello: Benchmarking Agent Protocol Handshake Overhead](https://arxiv.org/abs/2610.30151)
**Authors:** arXiv:2610.30151 (submitted 23 Oct 2026)
**TL;DR:** Benchmarks handshake overhead across three major agent communication protocols: MCP, A2A, and ACP. Provides empirical data on the latency and computational costs introduced by different agent protocol designs, informing choices for production multi-agent system architects.
**Tags:** `agents`, `protocols`, `MCP`, `benchmarking`, `multi-agent`

## [Multimodal Embodied Agents: A Unified Capability-centric Perspective from Computer-Use to Robot-Use](https://arxiv.org/abs/2610.30108)
**Authors:** arXiv:2610.30108 (submitted 21 Oct 2026)
**TL;DR:** A unified survey framing five core functions — perceive, anticipate, plan, act, verify — shared by computer-use agents and physical robot agents. Bridges the gap between desktop AI agents and embodied robotics, arguing these systems share a common capability architecture.
**Tags:** `embodied-ai`, `agents`, `multimodal`, `robotics`, `survey`

---

## [Hybrid Reasoning Agents](https://arxiv.org/abs/2610.18861)
**Authors:** arXiv:2610.18861 (submitted 13 Oct 2026)
**TL;DR:** Proposes dynamically switching between latent (chain-of-thought) reasoning and text-based tool use within a single generation process. This hybrid approach lets agents leverage the efficiency of internal reasoning while still calling external tools when needed, improving both speed and accuracy.
**Tags:** `agents`, `reasoning`, `tool-use`, `hybrid`

## [agent-risk: Risk Assessment for Changes to AI Agents](https://arxiv.org/abs/2610.16280)
**Authors:** arXiv:2610.16280 (submitted 12 Oct 2026)
**TL;DR:** Replays logged agent episodes to judge whether a proposed change to a deployed agent is safe to approve before rollout. Provides a principled safety review pipeline for iterating on production AI agents, reducing the risk of regressions in live systems.
**Tags:** `agents`, `safety`, `risk-assessment`, `deployment`

## [Embodied Playground: A Long-Horizon Agentic Robotics Benchmark](https://arxiv.org/abs/2610.27039)

**TL;DR:** Introduces a benchmark of 410 task environments spanning basic manipulation, sequential puzzles, and multi-stage household activities to evaluate long-horizon robotic agents. Covers physical, strategic, and spatial reasoning challenges, addressing gaps in existing short-horizon robot benchmarks.
**Tags:** `embodied-ai`, `robotics`, `benchmark`, `long-horizon`, `manipulation`

## [EmbodiedRSI: Active Continual Robot Learning Through Hypothesis-Guided Co-Evolution](https://arxiv.org/abs/2610.10498)
**Authors:** arXiv:2610.10498 (submitted 7 Oct 2026)
**TL;DR:** Addresses performance degradation in robot foundation models when object positions or task instructions change. Reports 86.8% overall success on LIBERO-Pro and 71.3% success across challenging tasks on a real robot with zero-shot transfer, via active continual learning guided by hypothesis generation.
**Tags:** `embodied-ai`, `robotics`, `continual-learning`, `VLA`, `zero-shot`

## [Can AI Agents Make Open-Ended Scientific Discovery? Evidence from Station](https://arxiv.org/abs/2610.08927)
**Authors:** arXiv:2610.08927 (submitted 6 Oct 2026)
**TL;DR:** Tests whether AI agents can autonomously rediscover scientific findings in an open-ended research setting. The Station system rediscovers 62.7% of findings on average versus 15.4% for a baseline, providing evidence that AI agents can meaningfully accelerate scientific research.
**Tags:** `agents`, `scientific-discovery`, `autonomy`, `research`

## [The Delegation Danger Band: When Sub-Agents Over-Trust Inherited State](https://arxiv.org/abs/2610.00041)
**Authors:** arXiv:2610.00041 (submitted Oct 2026)
**TL;DR:** Examines the failure mode where sub-agents in a multi-agent hierarchy uncritically inherit state assumptions from parent agents, leading to compounded errors. Characterizes the "delegation danger band" — the range of task complexity where single agents fail but multi-agent delegation also introduces trust-propagation risks.
**Tags:** `multi-agent`, `safety`, `delegation`, `trust`, `agents`
