# Top Papers — AI Agents & Embodied AI (2026-10-06)

## [PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents](https://arxiv.org/search/?searchtype=all&query=PACE+provenance+aware+capability+enforcement)
**Authors:** (October 2026, arXiv)
**TL;DR:** Proposes a provenance-aware system to prevent poisoning attacks on tool-using LLM agents via corrupted tools or memory. By tracking the origin of information used in agent decisions, the system can enforce capability boundaries that block adversarial manipulation.
**Tags:** `agents`, `safety`, `tool-use`, `adversarial-robustness`

## [TRACE: Trajectory Return Attribution and Contrastive Erasure for Multi-Turn Safety](https://arxiv.org/search/?searchtype=all&query=TRACE+trajectory+return+attribution+contrastive+erasure)
**Authors:** (October 2026, arXiv)
**TL;DR:** Addresses safety degradation in LLM agents over multi-turn interactions by attributing harmful outcomes to specific trajectory steps and erasing those via contrastive learning. This provides a principled mechanism for long-horizon alignment without full retraining.
**Tags:** `agents`, `safety`, `alignment`, `multi-turn`, `rlhf`

## [DAGent: Evaluate-then-Grow Planning for Deep Research Agents](https://arxiv.org/search/?searchtype=all&query=DAGent+evaluate+grow+planning+deep+research)
**Authors:** (October 2026, arXiv)
**TL;DR:** Introduces DAG-based planning that enables dynamic sub-task evaluation and growth in research agents, supporting parallel execution and adaptivity in complex knowledge-intensive tasks. The evaluate-then-grow paradigm significantly outperforms linear chain-of-thought planning on multi-hop research queries.
**Tags:** `agents`, `planning`, `DAG`, `research-agents`, `long-horizon`

## [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/pdf/2609.08589)
**Authors:** (October 5, 2026, arXiv)
**TL;DR:** Presents a memory orchestration system for LLM agents that dynamically curates multimodal memories (text, images, structured data) on demand. MemPilot enables more grounded reasoning and reduces hallucinations in agents operating over long contexts.
**Tags:** `agents`, `memory`, `multimodal`, `llm`, `long-context`

## [Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents](https://arxiv.org/search/?searchtype=all&query=Reconstruct+Practice+Go+Real+embodied+agents)
