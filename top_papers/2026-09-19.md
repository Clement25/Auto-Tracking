# Top Papers — AI Agents & Embodied AI (2026-09-19)

## [In-Context Robot Learning with VLM Agents](https://arxiv.org/abs/2609.19138)
**Authors:** Dongzhou Cheng, Taoran Yi, Ye Fang, Xingwu Zhang, Fan Feng, Yixuan Li, Gengxiong Zhuang, Rongze Wang, Shuai Yang, Wei Song, Weizhi Xue, Minyan Wu, Jie Gui, Jiaqi Wang, Tong Wu
**TL;DR:** Introduces GPT-Policy, a general-agent framework for in-context robot learning that integrates a context compiler preserving task-relevant visual transitions, a VLM proposing robot-tool actions, and a constrained controller that verifies and executes each step. In real-robot trials, human video demonstrations improve task completion even without robot action labels, while aligned action references yield further gains on contact-sensitive tasks.
**Tags:** `embodied-ai`, `robotics`, `vlm`, `in-context-learning`, `agents`

## [Social Laws for Multi-agent Coordination in Stochastic Environments](https://arxiv.org/abs/2609.18929)
**Authors:** Rolando Fernandez, Caleb Probine, Tyler Lee, Jeffrey Chen, Erez Karpas, Muhammad Arrasy Rahman, Peter Stone, Ufuk Topcu
**TL;DR:** Extends the concept of social laws to stochastic, reward-based multi-agent environments by introducing α-robustness — a measure of guaranteed utility each agent retains while pursuing its optimal single-agent policy assuming all agents obey the law. Presents an approach for robustness verification via reduction to solving a series of Markov decision processes. Appeared at the RIPL Workshop at ICAPS 2026.
**Tags:** `multi-agent`, `coordination`, `stochastic`, `agents`, `planning`

## [ORCH: Organizational Principles Enable Collective Intelligence in Embodied AI](https://arxiv.org/abs/2609.11737)
**Authors:** (Sep 10, 2026 submission)
**TL;DR:** ORCH constructs task-specific hierarchical organizations by combining pooled interdependence for concurrent work with sequential interdependence for prerequisite-governed tasks, enabling collective intelligence among embodied AI teams. The system dynamically assigns roles and coordination hierarchies to maximize team efficiency in long-horizon manipulation tasks.
**Tags:** `embodied-ai`, `multi-agent`, `coordination`, `robotics`, `collective-intelligence`

## [AgentLSD: Evaluating AI Security Agents Under Adversarial Task Contamination](https://arxiv.org/abs/2609.19140)
**Authors:** (Sep 16, 2026 submission)
**TL;DR:** Introduces a benchmark for evaluating AI security agents under adversarial task contamination — scenarios where malicious inputs are injected to mislead agent behavior during execution. ## [Cognitive Extensions for Dual-Process Language Agents: Memory and Self-Reflection in Interactive Environments](https://arxiv.org/abs/2609.19128)

## [Ask the Tool, Don't Guess: Agent Tool Calls Hold Their Progress, and the Serving System Should Read It](https://arxiv.org/abs/2609.18849)
**Authors:** (Sep 16, 2026 submission)
**TL;DR:** Demonstrates that agent tool calls inherently encode execution progress that serving systems currently ignore, leading to redundant computation and degraded agent performance. Proposes a stateful agent serving architecture that reads tool-call progress signals to eliminate recomputation and accelerate multi-step agent execution. Accepted to EMNLP 2026.
**Tags:** `agents`, `tool-use`, `llm-serving`, `efficiency`, `systems`

## [FolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects](https://arxiv.org/search/?query=FolDeX+deformable+robotic+manipulation&searchtype=all)
**Authors:** (Sep 9, 2026 submission)
**TL;DR:** Introduces FolDeX, a benchmark evaluating robots on long-horizon manipulation of deformable objects (clothing, cables, fabric) in physical environments. Addresses the gap in existing benchmarks that focus on rigid-body manipulation, providing standardized metrics for progress in deformable object handling.
