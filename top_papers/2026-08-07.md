# Top Papers — AI Agents & Embodied AI (2026-08-07)

## [World Action Models: The Next Frontier in Embodied AI](https://arxiv.org/abs/2605.12090)
**Authors:** Fudan University Research Team
**TL;DR:** Formally defines World Action Models (WAMs) as the convergence of Vision-Language-Action models and world models for embodied AI. Organizes existing methods into a taxonomy of Cascaded and Joint WAMs, subdivided by generation modality, conditioning mechanism, and action decoding strategy. Positions WAMs as the key next step beyond standalone VLA policies for robust robot learning.
**Tags:** `embodied-ai`, `VLA`, `world-models`, `robotics`, `foundation-models`

---

## [VLA-JEPA: Enhancing Vision-Language-Action Model with Latent World Model](https://arxiv.org/pdf/2602.10098)
**Authors:** (Multiple authors)
**TL;DR:** Proposes integrating a Joint Embedding Predictive Architecture (JEPA) as a latent world model to improve VLA policies for robot manipulation. The latent predictions provide a richer training signal than raw action supervision alone. Demonstrates improved generalization on out-of-distribution manipulation tasks.
**Tags:** `embodied-ai`, `VLA`, `world-models`, `robotics`, `JEPA`

---

## [Qwen-UI-Agent: Toward Next-Generation Real-World Centric Foundation GUI Agents](https://huggingface.co/papers)
**Authors:** Qwen Team, Alibaba
**TL;DR:** Introduces a unified GUI agent that handles mobile, desktop, browser, and deep-search scenarios within a single model. Achieves strong performance on real-world agentic benchmarks by grounding language understanding in visual UI perception. Represents a significant step toward general-purpose computer-use agents.
**Tags:** `agents`, `GUI-agents`, `computer-use`, `multimodal`, `foundation-models`

---

## [ROMA: Recursive Open Meta-Agent Framework for Long-Horizon Multi-Agent Systems](https://arxiv.org/list/cs.MA/recent)
**Authors:** (Multiple authors)
**TL;DR:** Proposes decomposing large tasks into subtask trees that run in parallel across multiple agents, enabling long-horizon workflows without exceeding individual context windows. The recursive meta-agent structure supports dynamic task spawning and result aggregation. Evaluated on complex software engineering and research tasks.
**Tags:** `agents`, `multi-agent`, `long-horizon`, `task-decomposition`, `orchestration`

---

## [ORCH: Many Analyses, One Merge — A Deterministic Multi-Agent Orchestrator](https://arxiv.org/list/cs.MA/recent)
**Authors:** (Multiple authors)
**TL;DR:** Presents a deterministic multi-agent orchestration system where multiple LLMs analyze a problem independently and a merge agent selects the best answer without any additional training. The approach reduces variance in complex reasoning tasks compared to single-model inference. Offers a training-free path to higher reliability in agentic pipelines.
**Tags:** `agents`, `multi-agent`, `orchestration`, `ensemble`, `reasoning`

---

## [AgentScope: Flexible Tool-Based Interactions for Agentic Applications](https://arxiv.org/list/cs.MA/recent)
**Authors:** (Multiple authors)
**TL;DR:** Proposes a unified agent framework built on the ReAct paradigm, offering flexible tool interfaces, advanced infrastructure, and unified agent APIs. Supports diverse tool types and enables seamless integration of heterogeneous capabilities within a single agent. Demonstrated across coding, web browsing, and data analysis tasks.
**Tags:** `agents`, `ReAct`, `tool-use`, `framework`, `infrastructure`

---

## [World Proxies for Embodied Agents: Dynamics, Spatial, Execution, Memory, Skill, and Reward](https://huggingface.co/papers)
**Authors:** Shanghai AI Laboratory
**TL;DR:** Organizes world model components into a taxonomy of proxies classified by feedback modality: dynamics, spatial, execution, memory/experience, skill, and reward/verification. Shows how these proxies enable agents during inference-time guidance, training-time optimization, and agent-proxy co-evolution. Provides a unified perspective on how world modeling can power next-generation embodied agents.
**Tags:** `embodied-ai`, `world-models`, `agents`, `survey`, `training`

---

## [Robots Need More Than VLAs & World Models](https://arxiv.org/html/2606.06556v1)
**Authors:** (Multiple authors)
**TL;DR:** Argues that while VLAs and world models have made major strides, real-world robot deployment still requires explicit task planning, safety-aware control, and reliable perception under distribution shift. Identifies key open challenges including sim-to-real transfer, long-horizon reasoning, and reactive safety. Calls for hybrid architectures combining learned and classical components.
**Tags:** `embodied-ai`, `robotics`, `VLA`, `safety`, `position-paper`

---

## [Security Considerations for Multi-Agent Systems](https://arxiv.org/pdf/2603.09002)
**Authors:** (Multiple authors)
**TL;DR:** Systematically analyzes attack surfaces unique to multi-agent LLM systems including prompt injection across agent boundaries, trust escalation, and tool misuse. Proposes a threat taxonomy and mitigation strategies at the orchestration layer. Critically relevant as multi-agent deployments move into production environments.
**Tags:** `agents`, `multi-agent`, `security`, `safety`, `adversarial`

---

## [AgenticPay: A Multi-Agent LLM Negotiation System for Buyer-Seller Transactions](https://arxiv.org/list/cs.MA/recent)
**Authors:** (Multiple authors)
**TL;DR:** Introduces a 110+ task benchmark for evaluating how well multi-agent LLM systems handle buyer-seller negotiations in natural language. The system features specialized negotiation agents with distinct roles and a shared transaction protocol. Results show current LLMs can handle routine negotiations but struggle with adversarial counterparties.
**Tags:** `agents`, `multi-agent`, `negotiation`, `benchmark`, `economics`

---

## [Exploring Robust Multi-Agent Workflows for Environmental Data Management](https://arxiv.org/html/2604.01647v1)
**Authors:** (Multiple authors, PEARC 2026)
**TL;DR:** Addresses agentic AI applied to scientific data management, targeting FAIR (Findable, Accessible, Interoperable, Reusable) data principles in environmental science. Demonstrates multi-agent workflows that automate metadata generation, dataset curation, and cross-repository linking. Presented at Practice and Experience in Advanced Research Computing 2026.
**Tags:** `agents`, `multi-agent`, `scientific-ai`, `data-management`, `FAIR`

## [Metis: Memory Foundation Model](https://huggingface.co/papers)
**Authors:** (Multiple authors)
**TL;DR:** Proposes a general-purpose memory foundation model that unifies episodic, semantic, and working memory into a single differentiable architecture for AI agents. Metis enables agents to persist, retrieve, and reason over long interaction histories more efficiently than retrieval-augmented generation baselines. Achieves state-of-the-art on several long-context agent benchmarks.
**Tags:** `agents`, `memory`, `foundation-models`, `RAG`, `long-context`
