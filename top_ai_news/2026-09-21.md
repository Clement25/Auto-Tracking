## [Plugin4Shell: Zero-Click RCE Vulnerability Hits Claude Code, OpenAI Codex, GitHub Copilot, and Gemini CLI](https://cybersecuritynews.com/)
**Source:** AIR Security / Cybersecurity News / Help Net Security
**Summary:** AIR Security disclosed Plugin4Shell on September 18 — a zero-click remote code execution vulnerability affecting four major AI coding agents. The exploit abuses the git checkout mechanism, allowing attackers to silently redirect commits to malicious code without the agent detecting the substitution. Anthropic (v2.1.179) and OpenAI (v0.146.0) have patched; GitHub Copilot and Gemini CLI remain unpatched or are deprecating affected components.

## [OpenAI's Hidden `__obi` Cross-Site Tracking Cookie Exposed](https://buchodi.com/)
**Source:** Buchodi (independent researcher)
**Summary:** Researcher Buchodi documented that ChatGPT generates a persistent `__obi` identifier bound to user accounts via JWT and transmits it to OpenAI from 12+ partner websites — including Chewy, Wayfair, HelloFresh, and Coursera — with a `SameSite=None` flag. The cookie remains active even when users are logged out and persists for 27+ days. Because it is classified as an analytics cookie, users who decline marketing consent still receive it, raising significant GDPR and CCPA compliance questions.

## [Google AX v0.3.0: Open-Source Agent Orchestrator Gains Traction](https://github.com/google/ax)
**Source:** GitHub / The Stack / Google Cloud Blog
**Summary:** Google released AX v0.3.0, an Apache-2.0 agent orchestration framework for workloads on its Agent Substrate infrastructure. The update splits the system into three microservices (API frontend, reconciler, sandboxed task runner) and migrates task state from Kubernetes custom resources to Redis Streams for better scalability. The project has ~3.7k GitHub stars and topped Hacker News with 214 points — emerging as a serious open-source alternative to proprietary agent frameworks.

## [TypeSafe AI Launches Jev: A Non-Text-Generating Foundation Model](https://techcrunch.com/)
**Source:** TechCrunch / TypeSafe Blog / AI News
**Summary:** TypeSafe AI released Jev, a novel foundation model that outputs decisions as calibrated probability distributions rather than text, trained via "Reinforcement Learning from Calibrated Decisions" (RLCD). The company claims Jev is up to 100× faster and 100× cheaper than comparable LLMs on classification and routing tasks, targeting real-time applications in games, robotics, and simulations. Founded by Diego Almeida (who claims a ChatGPT co-creator role), TypeSafe is positioning Jev as infrastructure for latency-sensitive agentic pipelines.

## [Provider-Side Token Inflation Attack: Dishonest AI Providers Can Covertly Inflate Outputs](https://arxiv.org/abs/2609.20370)
**Source:** arXiv (independent researchers)
**Summary:** Researchers demonstrated a new class of attack where AI providers covertly extend model outputs — inflating token counts by more than 10× the clean baseline — while maintaining apparent task utility to avoid detection. The paper proposes a black-box audit technique using output saturation effects that customers can use to detect inflation. The finding has immediate relevance to API pricing transparency and raises questions about the integrity of token-based billing models.
